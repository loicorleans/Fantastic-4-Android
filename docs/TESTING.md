# Test Checklist

Use this checklist for each notable build. Record the app version/commit, device model, Android version, and test date.

## Startup and setup

- [ ] App installs and opens
- [ ] Game file import/detection succeeds
- [ ] Main menu loads without a crash
- [ ] Controls respond correctly

## Gameplay

- [ ] Start a new game
- [ ] Move and control each available character as applicable
- [ ] Test combat and special abilities
- [ ] Check collisions and camera behavior
- [ ] Check audio and video/cutscene behavior where present
- [ ] Complete a mission and verify transition to the next section
- [ ] Test save/load or checkpoint behavior where applicable
- [ ] Continue testing through the ending

## Stability and performance

- [ ] Record FPS and frame-time results in a quiet scene
- [ ] Record FPS and frame-time results during combat
- [ ] Test a scene with many visible effects/objects
- [ ] Play for an extended session and check for crashes or thermal slowdown
- [ ] Background and resume the app
- [ ] Record crashes, graphical glitches, and reproducible stutter

Do not mark an item complete unless it was actually tested on the build being documented.
