# Compatibility

Record only results that have actually been tested. A game launch is not the same as complete compatibility.

## Current known test target

| Device / chipset | Android version | Launches | Playable | Full playthrough | Performance |
|---|---|---|---|---|---|
| Device using MediaTek Helio G80 | Record exact model/version | Yes, reported by developer | Yes, reported by developer | Not completed | Frame-rate stability still needs work; no verified benchmark recorded here |

The exact device model, Android version, RAM, app build/commit, and test date should be added when known.

## Suggested compatibility checks

- App startup and game import
- Main menu and loading screens
- Gameplay, combat, and effects
- Mission transitions and cutscenes
- Audio and controls
- Save/load behavior, if supported
- Long play sessions and thermal behavior
- Returning to the app after backgrounding it

Different devices and drivers can produce different results. Do not mark a device fully compatible based only on reaching the main menu.
