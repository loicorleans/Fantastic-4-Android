
## Bug reports

Please include as much of the following as possible:

- Device model and chipset
- Android version
- App/build version or commit
- Game mission, location, and what was happening
- Steps to reproduce the issue
- Expected behavior and actual behavior
- Whether the issue happens every time
- Relevant app/native logs, with personal information removed
- FPS or frame-time measurements if reporting performance

Do not attach copyrighted game executables, disc images, extracted game assets, account credentials, or other private information to an issue.

## Code contributions

- Keep changes focused and explain the reason for each change.
- Avoid mixing renderer changes with unrelated gameplay or UI changes in one patch.
- Test both correctness and performance when changing rendering code.
- Document device-specific results instead of assuming they apply to every device.
- Preserve required upstream license and attribution notices.

There is no guarantee that every proposed change can be merged. Compatibility and stability take priority over unverified performance claims.
